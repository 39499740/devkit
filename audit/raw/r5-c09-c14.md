## 最严重 8 条摘要

1. **C09 状态栏主文案语义反转（高）**：设计主槽位是具体结果文案（`Te0LC`，如「第 3 行缺少逗号」），代码主槽位是状态名「成功/失败」（`DkStatusBar.vue:20–28`、`:41`），`ok` 时信息量塌缩；且设计五态背景统一 `surface-subtle`，代码按状态染 soft 底（`:34`）。
2. **FileDrop 拖入不校验 accept（高，功能缺陷）**：`accept` 仅绑 `<input>`（`FileDrop.vue:67`），`onDrop`→`emitFiles`（`:34–37`）完全不校验，image/* 工具可拖入任意文件；同时组件无取消/移除/失败/进度，文件列表态未复用设计 `kWQyu`。
3. **C10 设计与代码组件职责错位（高）**：设计本体 `kWQyu` 是文件项（默认/读取中/失败/超限/完成，`iMTIx`），代码 `FileDrop.vue` 只是拖入区，文件项状态散落在 `t37-file-digest.vue:324–390`，无法复用；设计「超限项」在代码里退化为 toast（`FileDrop.vue:27`）。
4. **DkModal 无焦点陷阱（高，R04 a11y）**：只有 `role="dialog" aria-modal="true"`（`DkModal.vue:48–49`），无 Tab 循环，Tab 可离开面板且离开后 Esc 失效；关闭回焦（`:25`）与 Esc（`:30–32`）、点遮罩（`:42`）已实现。另 `danger` 仅加 `$warn` 图标（`:56`），`.dk-modal__panel--danger` 是无 CSS 的死类（`:46`）。
5. **C13 树形视图大面积缺实现（高）**：真实 T01 设计 `l7DyLg`/`D22md` 要求行高 24、值右对齐、类型标签 chip、容器「N 项」、工具条（全部展开/全部折叠/复制 JSON），`JsonTree.vue` 全部没有；`t01-json-format.vue` grep 无任何复制/展开/折叠入口。
6. **C13 JsonTree 行/缩进/箭头/预览偏差（中）**：设计 `MBSI5` 行高 28/gap6/radius6/padding[0,8]、缩进仅 12px 占位、chevron 图标、折叠值 `Object(4) {…}`、数组 `[2]` 键名；代码无行盒（`JsonTree.vue:61–71`）、用 `▾/▸` 字符（`:27`）、折叠无预览（`:32–33`）、数组子项无索引（`:40`）、缩进加虚线边框（`:77–81`）。
7. **C13 差异行表现与设计不符（高）**：设计「修改」是上下两行 `error-soft`/`ok-soft` 堆叠（`L4j5tK`），新增整行 `ok-soft`（`sssj4`）；代码单行 `old → new` 用 `--warn`（`t02-json-diff.vue:443–447`），整行无软底，只 badge 有底色（`:512–553`），且路径/旧值按 kind 整体染色，与设计「路径恒 code-key、旧值恒灰」不符（`:555–587`）。
8. **C14 折叠区缺摘要与结构化头部（高）**：设计 `M5DyY` 是图标底 26×26 + 标题 + **折叠摘要**（`cGbfa`）+ 「展开/收起」动作文字，展开态图标底 `accent-soft`（`qUoB4`）；`DkCollapse.vue` 只有 chevron + 标题（`:8–15`），无摘要、无图标底、无动作文字、无展开高亮。
