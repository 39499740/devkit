# R5 · 设计稿可复用组件 C01–C08 数值对齐审核

审核对象：`design.pen` 组件本体 + 变体板  vs  `devkit/app/components/*.vue`
审核方式：只读。设计值来自节点实际属性（`fill` 的 `$var` 已按 variables 的 light 值解析）；代码值来自 `<style>` 与模板。
设计变量 light 值见 `main.css`（与 variables 完全一致，仅 `--accent-hover` 为设计未定义）。

全局前提（影响所有组件）：
- `main.css:83 --radius: 8px`、`main.css:84 --radius-sm: 6px`。设计里圆角是逐组件写死的 5/6/7/8/9/10，代码大量把 `7/8/9` 统一压成 `--radius-sm: 6px` 或 `--radius: 8px`，是本轮最普遍的系统性偏差。
- `main.css:22 --accent-hover: #1d4fd7`、`:106 #6b9eff`：设计 variables 中不存在 `accent-hover`（已核实 `False`），属代码新增令牌。
- `main.css:238-250` 全局 `kbd`：`background: var(--surface-subtle)`、`border: 1px solid var(--border)` + `border-bottom-width: 2px`、`border-radius: 4px`、`font-size: 11px`、`color: var(--text-secondary)`。设计里的快捷键 chip 是 `fill: $surface`、`stroke: $border 1px`（四边等宽）、`cornerRadius: 5`、`font-size: 10`（mono）、`color: $text-tertiary`。TopNav / CommandPalette 的 kbd 都吃了这条全局样式，存在成组差异。
