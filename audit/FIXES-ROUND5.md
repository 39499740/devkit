## 1. 输入框（代码编辑器）尺寸 —— 已修

**问题**：工具页的编辑器实测只有 **124px** 高（内容区仅 62px），内容一多就整页变高；与设计稿（T01 编辑区 534px、面板 598px）完全不符。

**根因**：`DkEditor` 把 `height` 属性写在了 `.editor__body` 上，而该元素是 `.editor`（列 flex 容器）的子项并带 `flex: 1`——flex 主轴尺寸由分配决定，会**覆盖**内联 height；同时 `.editor` 自身用 `height: 100%`，父级高度为 auto 时塌缩，于是编辑器缩到最小内容高度。

**修复**（`app/components/DkEditor.vue`）：
- 把 `height` 应用在编辑器**根节点**（并提供 `min-height` 同值），`.editor__body` 由 `flex: 1; min-height: 0` 填充，textarea 内部滚动；
- 根节点加 `flex: 1 1 auto` 与 `min-height: 180px`，既不塌缩也能在分栏里等高于兄弟面板；
- 传递小高度（如 T33 的 96px token 输入框）时按工具意图生效，不再被最小高度顶大。

**验证**：
- 41 个工具逐页量测：有编辑器的 29 个工具，高度均在 200–900px 区间（唯一 96px 是 T33 的有意设置）；无 >900px 撑高、无 <200px 塌缩。
- 长内容实测：T01 粘贴 200 行 JSON → 编辑器仍 480px，textarea `scrollHeight 4221 / clientHeight 417 / overflow auto`，页面高度保持 900（不再随内容增长）。
- 截图：1440 下 T01 两个编辑器均为 480px，与设计比例一致。
