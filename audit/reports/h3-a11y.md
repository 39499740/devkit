## 2. 实现要点

### 2.1 DkSegmented（对应 6.4）
- 容器：`role="radiogroup"` + `:aria-label="ariaLabel || label"`；未传 label 时不渲染 `aria-label`（不编造名称）。
- 选项：`role="radio"` + `:aria-checked="modelValue === o.value"`；`type="button"`。
- 键盘：`@keydown` 在容器上处理 `ArrowRight/ArrowDown`（下一项）、`ArrowLeft/ArrowUp`（上一项）、`Home/End`；`preventDefault` 后 `emit('update:modelValue')` 并把焦点移到新选项；越界首尾环绕。
- roving tabindex：仅当前选中项 `tabindex="0"`，其余 `-1`；`modelValue` 不匹配任何选项时回退第一项。
- 视觉/API：`v-model`、`options`、`size`（sm/md）签名与类名、尺寸、配色全部保持不变；仅新增可选 props，老调用方无需改动。

### 2.2 DkSelect（对应 6.3）
- 新增可选 `label?: string`、`ariaLabel?: string`、`id?: string`；`select` 上 `:id="id"`、`:aria-label="ariaLabel || label"`。
- 未传入时不生成任何 aria 属性（保持原状，不伪造字段名）。
- 未新增任何 keydown/tabindex/role 覆盖，原生 select 的键盘与焦点行为完全保留。允许调用方用 `id` + `<label for>` 关联可见标签。

### 2.3 DkIconButton
- 可访问名：`ariaLabel || title || '按钮'`；两者都缺时开发期 `console.warn('[DkIconButton] 缺少可访问名称，请传入 title 或 aria-label')`，并给出可读兜底「按钮」。
- 触控目标：`@media (max-width: 768px), (pointer: coarse) { min-width/min-height: 40px }`；桌面端仍按 `size`（默认 30）显示，视觉不变。
- 焦点环：`.icon-btn:focus-visible { outline: 2px solid var(--accent) }`。
- `size` prop 通过 CSS 变量 `--icon-size` 真正生效（此前该 prop 未被使用）。
