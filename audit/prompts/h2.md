# 三个任务

## 任务 A：深色主题首帧闪烁（FOUC）
- 现状：usePrefs 在 onMounted 才应用主题（我刚修过，刷新后能生效），因此深色用户在首帧会看到浅色闪一下。
- 做法：在 nuxt.config 的 app.head 里加一段**内联脚本**（在样式之前执行），读取 localStorage 的 devkit.prefs.v1，直接给 <html> 加 dark 类、设置 --code-font-size 与 reduce-motion；仍需保证 usePrefs 后续逻辑一致（不要出现两套真相）。
- 注意 SSR：脚本只在浏览器执行，不能用 import；要处理 localStorage 不可用/数据损坏的情况。
- 验证：Playwright 里先写入 theme=dark 的 prefs，再 goto 首页并**在首帧**（例如 response 之后立刻 evaluate）检查 documentElement 是否已带 dark；并确认浅色用户不闪深色。

## 任务 B：字体自托管（去掉 Google Fonts 外链）
- 现状：nuxt.config 里 <link> 到 fonts.googleapis.com，与『纯静态 / 离线 / 隐私』定位冲突，且离线时字体回退。
- 做法：npm 安装 @fontsource/noto-sans-sc 与 @fontsource/jetbrains-mono（各取项目需要的字重：Noto 400/500/600/700，Mono 400/500/600），在 main.css 里 @import 或由 nuxt.config 引入其 css，并删除 Google Fonts 外链。
- 注意包体积：如体积过大（例如 Noto Sans SC 全量子集 > 8MB），报告实际体积并说明取舍；不要为此牺牲离线可视效果。
- 验证：构建后确认 HTML 里再无 fonts.googleapis/gstatic 引用；probe 页面 font-family 仍是 Noto Sans SC（或明确说明回退）；中文字形正常显示。

## 任务 C：真正的 PWA / 离线缓存（对应设计 S10）
- 现状：没有 Service Worker，/offline 只是说明页，断网后任何页面都打不开 → 与设计 S10『已缓存可处理 / 首次未缓存』不符。
- 做法：安装并配置 @vite-pwa/nuxt（registerType 用 autoUpdate；提供 manifest：name DevKit、short_name、theme_color #F4F5F7、图标用简洁几何/文字标识，符合任务书『没有现成品牌稿时用 DevKit 文字标识与简洁几何图形』；workbox 预缓存 js/css/html/字体与图标）。图标可用 python3 + PIL 生成 192/512 png（不要引入前端绘图依赖）。
- 更新 devkit/app/pages/offline.vue：按真实状态显示——Service Worker 已接管（可离线打开已缓存资源）时列出可离线使用的事实与范围；未接管时明确说明『首次访问尚未缓存』并给出重试（真实检测，不要空操作）。文案必须与真实能力一致，不要承诺『所有工具离线可用』。
- 开发服务器默认不注册 SW（vite-pwa 的 devOptions.enabled=false），这没问题；验证要用生产构建。
