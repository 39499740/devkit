## 2. 流程审计结论与验收样本

审计驱动方式（三条流程相同）：用仓库自带 esbuild 打包导入 `app/utils/workflow.ts` 的脚本后以 node 执行，走真实 runner 与执行器，与 `devkit/tests/run.mjs` 同一管线；Vue 页面层未在浏览器挂载（代码研读 + 逐行复刻纯函数验证，属材料注明的一贯局限）。数据流转结论：输入与中间结果全程页面内存传递（`runner.ts` 不读写存储），localStorage 仅存流程定义与运行摘要（不含输入与数据），三条流程均无密钥步骤。
