# DevKit：Pen 完整页面设计任务书

版本：1.0 · 2026-09-19  
用途：将本文整体交给 Pen，按批次完成全部设计画板与复用组件。本文是设计执行指令，不是网站代码需求。

## 00｜先执行本节：总指令

请作为产品设计师直接操作当前 Pen 文档，完成本文全部必需画板。不要只回复设计建议，不要只完成首页，不要把多个工具替换成一张泛化模板。可以分批设计，每批验证后继续，直到交付清单完成。

### 产品定位

DevKit 是面向 Java、Web、Vue 开发者的浏览器本地工具箱。输入、转换、摘要、加解密和文件处理均在用户设备上执行；网站可以静态部署。无账号、无云端历史、无需要远端计算的业务功能。页面使用中文，保留准确的英文协议名、算法名与技术字段。

### 现有设计如何处理

如果当前文件已有 DevKit 首页、JSON 格式化、SM4、顶部栏、侧栏组件：先读取这些画板和设计变量，以它们为视觉基准，复用并修订，不另起一套风格，不重复创建同名画板。若本文要求与旧稿冲突，以本文为准。其他无关设计保持原状。

已确认的示例事实：`DevKit-SM4-Key12` 为 16 个 ASCII 字符、16 字节；`DevKit-SM4-Secret-2024` 为 22 个 ASCII 字符、22 字节。不要把后者改成 20。现有 SM4 CBC 示例曾与 OpenSSL 对照通过，但只对当时的原始明文、空格、换行、密钥与 IV 成立；改任何数据后必须重算，不能沿用密文。

### 视觉与页面结构

- 浅色为主：浅灰底、白色面板、细边框、低强度阴影，蓝色主操作；红色只表达错误，绿色只表达成功，黄色表达待更新或提醒。
- 保留现有品牌；没有现有稿时用 DevKit 文字标识和简洁几何图形。避免大幅宣传 Hero、渐变装饰、玻璃拟态、无意义插画。
- 正文建议 14px，辅助文字 12px，代码 13–14px；按 4/8px 间距体系组织。若现有字号不同，优先保证阅读与密度一致。
- 顶部栏约 60px；左侧导航约 220–236px，可折叠；主区间距约 24px。工具详情必须把输入、参数、结果放在主要工作区。
- 每页只高亮当前工具或当前入口；工具页不要同时高亮“全部工具”。分类可折叠，长侧栏独立滚动；不要为消除检查器提示而强制展开所有分类。
- 全站导航分类：数据格式、编码与文本、摘要与加密、时间与标识、Java 开发、Web / Vue、接口辅助、文件与图片。Java、Vue 同时可以作为工具标签。
- 全局搜索支持中文、英文、缩写和别名。桌面显示适合系统的快捷键提示，不将 macOS 快捷键当成唯一操作方式。
- 长行支持横向滚动或可控换行，不能简单裁掉。输入输出分栏允许拖动分隔线；小屏改成纵向排列或清楚的输入/输出标签页。
- 每页显示简短“本地处理”，完整说明放在帮助页。密钥、Token、原始文件与输入正文不默认持久化。
- 不设计登录、付费墙、云端同步、广告、聊天助手、服务器代理、在线 JVM、Maven 构建或数据库连接。

### 数据与交互真实性

1. 所有状态栏字符数、字节数、行数、文件大小都要从实际示例推导；不能手填彼此矛盾的数字。明确字节数依据 UTF-8 还是解码后的原始字节。
2. 加密、摘要、校验和、签名等结果要来自真实计算。不能运行验证时使用无结果状态或明确写“演示结果，待实现验证”，不能伪造“验证通过”。
3. 不静默 trim、改变换行、替换字符编码或损失大整数精度。会改变数据的选项必须可见。
4. 用户修改输入或影响计算的参数后，旧输出进入“待更新”；可保留查看但默认禁止复制下载，重新执行成功后恢复。
5. 解码、解析、格式正确、验签成功必须使用不同文案。JWT 解码成功不等于签名有效。
6. 复制内容不包含行号、地址偏移、语法提示或展示性换行。对需要真实换行的文本保留原文换行。
7. 文件处理提供文件名、大小、移除、进度、取消、失败反馈；不能显示“上传中”，使用“读取中/处理中”。
8. 禁用态、聚焦态、选中态、悬停态、复制成功、取消执行都应在组件或状态页中有定义。
9. 仅将工具 ID、非敏感参数作为分享配置；不把输入、密钥、Token 放入 URL。跨工具传递发生在内存中，目标需支持该类型。
10. 页面文案不得提前承诺“所有大文件流畅”“永不失败”“完全安全”。离线状态应区分已缓存和首次未缓存工具。

### 画板与变体规则

- 每个工具必须有独立的标准桌面主画板，宽 1440，首屏参考高度 900；页面可自然纵向延长，不为塞进一屏压缩文字。
- 每个工具条目列出的“必画变体”都必须成为独立命名画板，不只写在说明里。避免无意义的参数组合穷举。
- 全站统一状态只需在第 02 节画一次；工具特有状态按第 03 节逐项绘制。
- 第 04 节列出的响应式和深色代表页必须独立绘制。
- 名称格式：`T01 / JSON格式化 / 成功 / 1440`，系统页使用 S 编号，共享状态使用 G 编号，组件使用 C 编号。
- 每个工具旁放不计入网页内容的设计注释：处理方式、参数联动、复制规则、待更新规则、输入是否持久化、真实校验情况。
- 禁止将内部实现术语、节点 ID、测试日志写进面向用户的页面。可放在设计注释。

## 01｜网站入口与支持页面：逐页提示词

本节每个编号均需独立画板，并复用统一外壳。

### S01｜首页 / 全部工具
请设计紧凑工具目录。保留顶部搜索、左侧分类，正文有一句产品说明、首页搜索、收藏快捷区、最近使用和按分类排列的工具卡片。卡片含图标、名称、一句用途、收藏按钮和必要标签；点击标题区域打开工具，收藏按钮独立操作。所有工具名称来自第03节，不编造额外功能。首页搜索和顶部搜索共享结果规则。初次访问没有历史时展示推荐工具，不编造用户记录。补一个首次访问变体。

### S02｜分类列表
请以“摘要与加密”为实例设计分类列表：分类标题、用途说明、当前分类搜索、工具数量和工具卡片。分类切换不丢失导航。区分摘要、对称加密、非对称加密，但不另建复杂多层导航。补“Java 开发”分类变体，显示 JSON 转 Java、转义、配置转换、堆栈、Maven 声明转换、Cron 等相关入口，同一工具使用同一路由。

### S03｜全局搜索
请设计命令面板形式的全局搜索弹层，包含输入框、分组结果、名称、分类、简短描述、键盘选择和关闭提示。用“国密”展示 SM2/SM3/SM4 结果；再画“无结果”状态，允许修改关键词或回到全部工具。搜索只搜索工具目录，不搜索用户输入内容。

### S04｜我的收藏
请设计已收藏工具列表，支持取消收藏和排序，复用卡片。补空收藏状态，提供“浏览全部工具”。收藏只保存工具标识，不保存输入数据。

### S05｜最近使用
请设计按今天/更早分组的工具记录，可移除单条和清空全部。记录只含工具名称和访问时间，不展示之前处理的正文、密钥、Token或文件名。补空历史状态。

### S06｜偏好设置
请设计浅色/深色/跟随系统、代码字号、编辑器自动换行、默认缩进、减少动画、是否记录最近使用等设置。设置本地保存，敏感输入不保存。提供重置偏好和清除本地偏好/收藏/工具访问记录，明确范围并用一个确认弹层说明，不使用模糊“清空全部数据”。

### S07｜本地处理与隐私说明
请用易读说明页解释浏览器本地计算、静态资源仍需加载、可保存的偏好类型、输入不默认持久化、剪贴板和下载由用户主动触发。明确网站并不提供云端历史。离线可用性以缓存状态为准。提供返回工具入口，不编造认证标志。

### S08｜帮助与快捷键
请设计工具检索、导入文件、复制下载、参数编码、字符和字节区别、结果待更新的帮助页；快捷键同时展示 Windows/Linux 与 macOS 对应形式。操作必须都有可点击入口。提供反馈入口的界面位置，但不伪造实际邮箱、仓库链接或工单提交结果。

### S09｜工具不存在 / 404
请设计简洁空状态：工具不存在或链接已失效，提供搜索、返回首页、常用工具。保留统一导航，避免大幅插画。

### S10｜离线与资源未就绪
请绘制两个状态：已缓存工具可继续本地处理；首次访问未缓存工具无法加载，提供重试与已缓存工具列表。离线不等于所有工具不可用，也不能声称所有工具均已缓存。

## 02｜共享交互与状态：逐项画板

### G01｜发送到另一个工具
从 Base64 解码结果打开“发送到…”菜单，只列出兼容的 JSON 格式化、文本差异等目标。展示目标已有未保存输入时的替换确认，以及成功进入目标后的轻量提示。转换失败时不传递伪结果。传递仅在当前浏览器内存中进行。

### G02｜文件处理过程
以文件摘要为例绘制拖入高亮、读取中、计算进度、取消完成、读取失败、文件超出当前限制六个状态小画板。进度不确定时不编造百分比；大文件限制使用明确可配置占位说明，不虚构已支持的容量。

### G03｜剪贴板与下载反馈
绘制复制成功、剪贴板权限不可用时的手动选择提示、下载准备完成、下载失败反馈。提示不覆盖输入内容，不自动重复提交。

### G04｜输入已修改 / 结果待更新
以摘要工具展示编辑前后：原成功结果保留但明显标为旧结果，复制下载禁用，提供重新计算。文案简洁，颜色与真实错误区分。

### G05｜首次进入与示例数据
设计通用空输入、示例入口、载入示例将替换现有内容时的提示。用户无现有输入时直接加载，不弹无意义确认。测试密钥示例明确只用于测试。

### G06｜执行失败与重试
设计算法不支持、解析失败、任务取消三种不同反馈。不把用户参数错误写成系统崩溃；保留输入，定位具体字段，允许修改后重试。

### G07｜长内容工作台
以 JSON 展示长行横向滚动、自动换行、左右分栏调整、只看输入/只看输出、编辑器内查找。行号和折行不混淆，不将数据截断伪装成完整结果。

### G08｜危险渲染内容预览
以 SVG 展示源码区和隔离预览区，清楚标示不执行脚本、不加载外部资源；不允许设计中的预览访问远程资源或自动运行用户代码。提供安全预览无法完整还原时的提示。

## 04｜响应式、深色与可访问性提示词

### R01｜1366×768 工作屏幕
请分别绘制：首页、JSON格式化成功、SM4加密成功、JSON转Java、多文件摘要、图片压缩六个小屏桌面变体。首屏必须能发现主按钮、输入和输出；说明区自然延伸到首屏下方。侧栏可滚动，不裁掉底部入口；工具条不挤压成不可读字符。已有合格画板直接复用。

### R02｜390×844 移动端
请分别绘制：首页、搜索弹层、JSON格式化、SM4加解密、图片压缩五个手机页面。侧栏改抽屉，触控目标建议至少44px，双栏改输入/结果标签页或纵向布局，参数可折叠但必填错误必须可见。主按钮可固定在底部，但不得遮住编辑器与系统安全区。横向代码滚动限制在编辑器内，不导致整个页面横向滚动。另画导航抽屉展开状态。

### R03｜深色主题
请绘制首页、JSON格式化、SM4三个深色代表页，并定义全部颜色变量的深色值。背景、边框、正文、语法高亮、错误、警告、禁用态保持层级，不简单反色。其他工具通过变量继承，无需重复全部画板。

### R04｜可访问性检查样板
请绘制键盘聚焦、输入错误与成功提示的组件样板。错误不能只靠颜色表达；图标按钮有可访问名称注释；正文和控件对比度应检查；Tab顺序遵循视觉顺序，模态框关闭后焦点回到触发入口。减少动画设置有明确行为注释。

## 06｜执行批次与检查方法

按以下顺序推进，在同一份Pen文件内交付。每批结束先检查，再继续下一批，不必等待用户重复输入。

1. **基础规范：**读取已有稿，建立C组件与变量，补S01–S03。
2. **通用转换：**T01–T11，完成所有指定变体。
3. **密码学：**T12–T17，优先校验数据和参数联动；未核验内容不得显示成功证明。
4. **时间与Java：**T18–T26，区分方言、时区和类型推断。
5. **Web与接口：**T27–T36，不执行用户代码、不发起真实接口请求。
6. **文件：**T37–T41，补进度、取消、失败与下载语义。
7. **系统与状态：**S04–S10、G01–G08，完成缺失的交互闭环。
8. **适配与验收：**R01–R04，逐页检查与最终截图。

如果单轮无法完成全部设计，保留已完成画板，列出下一批准确编号；续做时先读取清单，不重复生成。不要把“已建容器”当成已完成页面。

### 每批必须执行的检查

- 从实际节点读取画板、文字、选中样式和示例，不以之前的聊天总结代替。
- 检查溢出、重叠、文字截断、侧栏高度、工具条宽度、说明区是否被裁掉。
- 检查每页只有一个当前导航；加密/解密、输入/输出、参数类型彼此一致。
- 示例输入输出相符；没有旧密文配新明文、错误页出现成功徽章、空输出仍可复制等矛盾。
- 明确布局检查器报错是真问题还是隐藏节点边界问题；保留合理分类折叠，不单纯为零报错改变交互。
- 已完成画板清除placeholder/Generating标记，不留空白占位框。
- 截图检查每个主画板及关键变体；对小屏、长内容、表单密集页重点放大检查。
