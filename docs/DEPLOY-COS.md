# 部署到腾讯云对象存储（COS 静态托管）

## 0. 先回答：放 COS 会影响我的备案吗？

**结论：备案不会自动失效，但存在「接入信息与实际不一致」的合规风险；并且绝对不能退掉那台轻量服务器。**

依据（腾讯云官方文档，本站抓取于 2026-09-20）：

1. 「ICP 备案 › 备案云资源」（更新于 2026-08-13）列出的**可用备案资源**只有：
   云服务器 CVM、轻量应用服务器 Lighthouse、Serverless（云函数资源包）、负载均衡实例、云开发、云托管。
   → **对象存储 COS 不在备案资源清单内，不能作为备案的接入资源。**
2. 「对象存储 › 开启自定义源站域名」（更新于 2026-06-23）：
   绑定自定义域名时 *“请确保输入的域名已备案”*，且 *“COS 的域名接入检查的是网站备案的结果，如果只是做过 App 备案无法接入”*。
   → 也就是说：**放到 COS 反而依赖你已有的备案**，不存在“放 COS 就不用备案”或“备案会失效”。
3. 「对象存储 › 静态网站 FAQ」：
   *“静态网站功能配合前端 Vue 框架一起使用，当路由设置为 History 模式，刷新页面遇到 404 问题怎么办？请在存储桶的静态网站配置页面，将错误文档配置为 Web 应用的入口（一般为 index.html），并将错误文档响应码设置为 200。”*
   → 这是 COS 对 SPA/History 路由的官方推荐配置（本项目按此配置）。

**风险与红线**

| 事项 | 说明 |
|---|---|
| 备案记录 | 不会因为内容搬到 COS 而自动变化；备案仍绑定「主体 + 域名 + 接入商 + 接入资源（轻量服务器）」 |
| 不一致风险 | 你的实际服务资源是 COS，而备案登记的接入资源是轻量服务器。管局/接入商的**备案信息准确性核查**、年报、举报核查时可能要求整改 |
| **红线 1** | **不要退订/让轻量服务器过期**。腾讯云要求备案期间云资源剩余有效期 ≥ 1 个月，资源失效会被「取消接入」→ 备案注销 |
| **红线 2** | **对外必须使用自己的已备案域名**。COS 默认域名（`xxx.cos.ap-xxx.myqcloud.com`）不能备案；静态网站域名也不适合作为主站 |
| **红线 3** | 已备案网站需在页脚展示 **ICP 备案号**并链接 `https://beian.miit.gov.cn`；如办了公安联网备案还需展示公安备案号并链接 `https://beian.mps.gov.cn`。**本项目目前没有页脚备案号，需要补**（见文末待办） |

**推荐做法（稳妥度从高到低）**

1. **保留轻量服务器（继续续费，不承担站点流量）+ 站点放 COS + 已备案自定义域名** —— 成本最低、日常无问题，属于业内最常见做法。
2. 想更严格一致：让轻量继续承载站点，前面加**腾讯云 CDN**（加速域名同样要求备案），流量走 CDN 单价更低、回源流量小。
3. 若管局要求资源一致，走腾讯云备案控制台的「变更备案 / 新增接入」调整接入资源。

## 1. 为什么这个项目适合静态托管

- 零后端：所有计算在浏览器内完成，无账号、无云端存储；
- `npm run generate` 会预渲染全部路由，产物纯静态；
- 流量成本：COS 按实际流量计费（另加少量存储/请求费），比轻量服务器按流量计费更低，且无运维；
- 自带 PWA（Service Worker），配合 HTTPS 可离线使用已缓存页面。

## 2. 生成静态产物

```bash
cd devkit
npm run generate        # 产物目录：devkit/.output/public
```

产物内容（实测）：

- `index.html`、`200.html`、`404.html`、`offline-fallback.html`
- 各路由目录 + `index.html`（共 56 个，含 41 个工具页）
- `_nuxt/` 静态资源（JS/CSS/字体）、`sw.js`、`workbox-*.js`、`manifest.webmanifest`、PWA 图标
- 预渲染路由数：114

## 3. COS 配置步骤

1. **创建存储桶**：地域选国内（如 `ap-shanghai`），访问权限按需（推荐「私有读写」，通过自定义域名/CDN 访问；或「公有读私有写」）。
2. **上传产物**：把 `.output/public/` 下的**全部内容**同步到桶根目录（不要把 `public` 目录本身套一层）。
3. **开启静态网站**（存储桶 → 基础配置 → 静态网站）：
   - 索引文档：`index.html`
   - 错误文档：`index.html`
   - **错误文档响应码：200** ← 关键，用于兜住不带尾部斜杠的深链（如 `/tools/base64`）
4. **绑定自定义域名**（存储桶 → 域名与传输管理 → 自定义源站域名）：
   - 源站类型选「静态网站源站」；开启强制 HTTPS（需先上传证书）
   - 按提示到 DNSPod 添加 CNAME 解析（`<桶名>.cos.<地域>.myqcloud.com` 或静态网站域名）
5. **（可选但推荐）腾讯云 CDN 加速**，缓存策略：
   - `/_nuxt/*` → 长缓存（1 年，immutable）
   - `/sw.js`、`/manifest.webmanifest`、`*.html` → 不缓存或短缓存（保证发版即生效）
   - 其余静态资源按需
6. **Content-Type 检查**：确保 `.js`=`application/javascript`、`.woff2`=`font/woff2`、`.webmanifest`=`application/manifest+json`（COS 一般自动识别，可用 `coscli` 上传时指定）。

## 4. 一键部署脚本

见 `scripts/deploy-cos.sh`（基于腾讯云官方 `coscli`）：

```bash
brew install tencentcloud/tools/coscli   # 或从官方 release 安装
coscli config init                        # 配置 secretId/secretKey/bucket
scripts/deploy-cos.sh                     # 生成 + 同步 + 清理旧文件
```
